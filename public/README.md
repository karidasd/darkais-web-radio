## 🎧 Overview
**DarkAIs Web Radio** is a high-performance, cyberpunk web radio station and DJ console built for developers, electronic music producers, and underground rave enthusiasts. It combines **24/7 global underground audio streams**, real-time **3D audio-reactive laser visualizers**, a **play-along analog acid synth**, an **AI Cyber Voice DJ drop engine**, and a **local drag-and-drop AI jukebox** into a zero-latency, serverless web app.

---

## 🎛️ Key Features

### 1. 📡 8 Curated Global 24/7 Underground Streams
- ⚡ **Berlin Underground Dark Techno (140 BPM)** — Industrial & heavy warehouse kicks
- ☣️ **90s Acid Rave & Hardcore (150 BPM)** — Squelchy Roland TB-303 resonance & breakbeats
- 🏴‍☠️ **Pirate Drum & Bass / Neurofunk (174 BPM)** — High-velocity Reese sub-bass
- 🌌 **Cyberpunk Darksynth & Midtempo (115 BPM)** — Dystopian analog synth groove
- ⚡ **Industrial Darkwave & EBM (128 BPM)** — Cold electro body music
- 🌀 **Dark Psytrance & Forest Goa (148 BPM)** — Hypnotic rolling frequency modulation
- 🚀 **French Cyber Electro & Complextro (128 BPM)** — Distorted Justice-style stabs
- 🍵 **Dark Lo-Fi Cyber Coding Beats (85 BPM)** — Rainy cyberpunk chill for deep programming

### 2. 🌌 Realtime 3D Laser Tunnel Visualizer & Shockwaves
- **Pulsing Cyber Hexagon Tunnel & Laser Beams** reacting dynamically to live stream bass and tempo.
- **Interactive Click Particles:** Click anywhere on the canvas to trigger exploding neon laser bursts and strobe shockwaves!
- **Modes:** 3D Laser Tunnel, Neon Spectrum Bars, Oscilloscope Waveform, and Fullscreen Mode (`📺 FULLSCREEN`).

### 3. 🎹 Play-Along Cyber Mini Synth (Studio Keybed)
- 1-octave authentic hardware keybed with white keys and sharp 3D black keys.
- Play live acid synth leads **over the radio stream** using your mouse or computer keyboard (`A, W, S, E, D, F, T, G, Y, H, U, J, K`).

### 4. 🤖 AI Cyber Voice DJ Drop Engine (Text-to-Speech)
- Type any custom drop message and broadcast it live with robotic vocoder speech synthesis!

### 5. 🎲 Suno AI Prompt Roulette
- 1-click generator for creative, production-ready prompts to synthesize custom tracks on **Suno AI** and **Udio**.

### 6. 📂 Local MP3 Drag & Drop Jukebox
- Drop any local `.mp3` or `.wav` track into the dropzone to play custom AI tracks through the visualizer engine.

### 7. 📊 Dual LED VU Peak Decibel Meters
- Left/Right LED signal meters (Green ➔ Yellow ➔ Red Clip) reflecting audio dynamics.

### 8. 🎨 4 Cyberpunk Theme Skins
- 🟣 **Cyber Cyan** (Default DarkAIs)
- 🟢 **Matrix Terminal Green** (00s Hacker Theme)
- 🔴 **Cyberpunk Crimson & Gold** (Night City)
- 🌅 **80s Synthwave** (Outrun Neon Pink)

### 9. 📱 Progressive Web App (PWA)
- Installable on Windows, macOS, iOS, and Android as a standalone desktop/mobile app.

---

## 🛠️ Tech Stack
- **Audio Engine:** HTML5 Audio API + Web Audio API (BiquadFilter, Oscillator, Gain, Analyser, WaveShaper)
- **Visuals:** HTML5 Canvas (3D Math Matrix, Time-Domain Oscilloscope & Particle Physics)
- **Speech:** Web Speech Synthesis API
- **Deployment:** GitHub Pages (Zero-Server, Zero-Cost, 100% Client-Side)

## 💻 Local Development
```bash
# Clone the repository
git clone https://github.com/karidasd/darkais-web-radio.git

# Navigate to the folder
cd darkais-web-radio

# Start local server
npm start
# Open http://localhost:3003 in your browser
```
